The Wildlife project aims to develop a wildlife observation platform where
users can share photos and videos of wild animals. The
information generated by these posts—such as GPS coordinates, the date, and
the species—will be used by wildlife professionals, such as
zoologists and biologists. Artificial intelligence plays a central role in this
project, particularly for the automatic recognition of animal species based on
images provided by users and connected cameras.
Classifying animal species from images is a complex challenge that
requires high-performance image processing and machine learning
algorithms. Convolutional neural networks (CNNs) have proven effective in
this field, particularly for image classification tasks. Transfer learning,
a machine learning technique, is commonly used to adapt a pre-trained model
to new data, thereby facilitating the creation of an animal species recognition
model for the Wildlife project.
In this research report, we present the development of an AI system designed for
animal species classification as part of the Wildlife project, exploring different
CNN architectures and using transfer learning to optimize the performance of
our model.
